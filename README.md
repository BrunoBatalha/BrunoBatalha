## 🎯 Código que resolve — e que dá gosto de evoluir

Sou desenvolvedor de software na **Venturus**, com foco em criar produtos web que equilibram boa experiência, qualidade técnica e objetivo de negócio. Gosto especialmente de transformar ideias em interfaces bem resolvidas, sem perder de vista o que acontece por trás delas.

> **Minha regra de ouro:** começar pelo problema, construir com clareza e refatorar com intenção.

## ⚡ Onde eu gero valor

| 🎨 Para o produto | ⚙️ Para a engenharia |
| --- | --- |
| Interfaces que tornam decisões e fluxos mais simples | Código sustentável, APIs bem definidas e evolução contínua |
| Olhar de frontend com visão de ponta a ponta | Clean Code, TDD, Git Flow e arquitetura limpa |
| Interesse genuíno por empreendedorismo e impacto | Colaboração entre frontend, backend e dados |
