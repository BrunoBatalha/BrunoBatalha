## Código que resolve — e que dá gosto de evoluir

Sou desenvolvedor de software na **Venturus**, com foco em criar produtos web que equilibram boa experiência, qualidade técnica e objetivo de negócio. Gosto especialmente de transformar ideias em interfaces bem resolvidas, sem perder de vista o que acontece por trás delas.

Minha abordagem é simples:

- **Começar pelo problema**, não pela tecnologia da moda;
- **Construir com clareza**, para que produto, time e usuário caminhem juntos;
- **Refatorar com intenção**, porque um bom software também precisa continuar bom amanhã.

## Onde gero valor
